# Умная теплица (IoT Smart Greenhouse)

Учебный веб-прототип на HTML, CSS и JavaScript.

## Запуск
1. Распакуйте архив.
2. Откройте папку проекта в VS Code.
3. Запустите `index.html` через расширение Live Server (рекомендуется).
4. Для графиков требуется подключение к интернету, так как Chart.js загружается с CDN.

## Реализовано
- Панель показателей и минимум 3 зоны.
- 6 типов датчиков и автоматическая симуляция значений.
- Ручной и автоматический режимы устройств.
- Блокировка насоса при низком уровне воды.
- Оповещения, журнал событий и экспорт журнала в CSV.
- 4 графика, оценка риска и рекомендации.
- Настройки порогов, фильтры, localStorage и адаптивный интерфейс.

Все показания являются учебными и не связаны с физическим оборудованием.
